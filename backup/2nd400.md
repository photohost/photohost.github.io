# 網站大改中

自從使用了codex直接上癮，本來追求簡單可以用就好的日記網站，漸漸有了我想要的功能與外觀，玩上癮就是了。主要是寫作頁面直接在notion內處理，一是手機可以隨時隨地上傳(只有單檔限制，上傳占無限制)，所以不用額外把圖片丟到我自己的圖床。不過升級到plus還常常額度用完，不過自己的想要的網站開始成形了，很有趣

# 麥當勞

一直想要戒除，但是最近有周年活動還是把app下載了。麥當勞最吸引我的就是快速結帳與點餐，還有吃完直接丟垃圾桶的好處，不用煩惱分類，零接觸點餐非常吸引我...主要是貪吃。今天聽到有優惠老實下載吃了1+1以及雙份雞翅，好吃但每次吃完小後悔qwq<br> 小時候都吃不到麥當勞，連學生時期也對麥當勞買得戰戰兢兢，印象中小時候吃麥當勞的次數介於有或沒有之間，記憶很模糊，每次經過都很想吃，可是我知道家人是不可能讓我吃的，只有考好成績或做對事才會吃到，這些我怎麼可能會發生在我身上呢？或許是彌補童年的遺憾，儘管吃膩了還是會去吃，想到覺得我自己很對不起小時候的自己

# 好吃粉

昨天和150上班，聊到北海道買的戰利品有哪些，因為當初一起逛藥妝店，剛好想到好吃粉這東西。150本身不太喜歡食物沾調味料，應該是也不愛過多調味的東西，但他一直想嘗試吃看看。我本來就會四處沾東西的人，當時在藥妝店看到挺大罐的，架上剩下這個高階的版本(金色包裝)，好像900多日幣我就買下來。150想嘗試看看，我就說：你帶瓶子來我分給你。<br> 然後他今年拿著空瓶子過來，我就分給他了，本來他說要一點點而已，我直接選擇裝到滿為止<br>

# 行李束帶

我出國很少用這個東西，但聽到可以白嫖還是拿了。當初北海道旅行本來說沒要送，我也不打算去要，結果今天旅遊社直接寄了一箱束帶過來，我就去拿了一條(配色醜但是很亮眼)<br> 我有一個軟的黑色行李袋，如果改天還會用到行李袋去託運，我就會想用這個了，我真的很怕弄錯行李，都是黑色的辨識度其實蠻差的

# 線香

從去年開始就要在關注這線香盒，日本無印才有賣，我去了台灣跟越南都沒有賣這個，去年去福岡沒看到，八月去東京沒有仔細找，剛好這次北海道讓我碰到了！當然二話不說買下來，好像是700多日幣，跟同事湊免稅所以先讓同事付錢，結果因人情問題這東西算我免費拿到了，總是好賺。今天家人去無印詢問我要買甚麼，我二話不說想到線香，他買了金木犀的味道，甜甜的，因為很怕阿貓吸到所以只點在我房間，小小的不占空間又很雅致，比起擴香石滴油之類的方便很多
